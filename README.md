# Figma Skincare Web

Figma의 `skincare-landing-page` 프레임을 HTML/CSS/JavaScript로 옮긴 반응형 웹 연습 프로젝트입니다.

## 파일
- `index.html`: 웹페이지 구조와 콘텐츠
- `style.css`: 디자인, 레이아웃, 반응형
- `script.js`: 모바일 메뉴와 FAQ 동작

## 실행
`index.html`을 브라우저에서 열면 됩니다.

## 디자인 출처
Figma 디자인을 ChatGPT와 연동하여 구조를 분석한 뒤 웹 코드로 구현했습니다.

> 현재 Figma 이미지 영역이 실제 이미지 에셋이 아닌 Rectangle 구조라 CSS 플레이스홀더로 구현했습니다.
